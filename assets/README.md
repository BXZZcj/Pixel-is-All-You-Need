# Bundled fonts

The three TTF files in this directory report version 1.07.4 in their embedded metadata:

- `LiberationMono-Regular.ttf`
- `LiberationSans-Regular.ttf`
- `LiberationSans-Bold.ttf`

LIBERATION is a trademark of Red Hat, Inc.

These fonts use the older Liberation Fonts license (GNU GPL version 2 with the
Liberation font exceptions), rather than the SIL Open Font License used by Liberation 2.x.
The font files are kept unchanged because they define the rendered training and test canvases.

`License.txt` contains the Liberation license agreement and exceptions; `COPYING`
contains the GNU GPL version 2. Both texts are copied from the official upstream repository:

- https://github.com/liberationfonts/liberation-1.7-fonts/blob/liberation-fonts-1_07_3/License.txt
- https://github.com/liberationfonts/liberation-1.7-fonts/blob/liberation-fonts-1_07_3/COPYING
- Font project and source: https://github.com/liberationfonts/liberation-1.7-fonts

The repository's top-level MIT license applies to the project code, not these third-party fonts.
